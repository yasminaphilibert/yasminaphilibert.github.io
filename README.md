# Yasmina Philibert — Portfolio

Personal portfolio site for Yasmina Philibert (YΛSYNTHΛ), creative director & visual artist.

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Local development

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```

Deployed via GitHub Pages from this repository (`yasminaphilibert.github.io`).
